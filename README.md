# Docker Compose & Container Monitoring Lab

## Overview
This academic lab explores multi-container application
deployment and basic container monitoring using Docker
Compose, Prometheus, cAdvisor, and Grafana.

## Technologies
- Docker and Docker Compose
- Nginx
- Flask (Python)
- Redis
- Prometheus
- cAdvisor
- Grafana

## Application Architecture
- Nginx acts as a reverse proxy for the web application.
- Two Flask application instances provide web services.
- Redis runs as a supporting service.
- Prometheus collects monitoring metrics from cAdvisor.
- Grafana visualizes the collected metrics.

## Practical Experience
- Used Docker Compose to manage a multi-container application.
- Tested Flask services and Nginx routing through a web browser.
- Verified monitoring targets in Prometheus.
- Configured Grafana to display monitoring information.
